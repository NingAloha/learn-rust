## `match` 控制流运算符

Rust 有一个非常强大的控制流运算符，称为 `match`，它允许您将一个值与一系列模式进行比较，然后根据匹配的模式执行代码。模式可以由字面值、变量名、通配符以及许多其他元素组成；[Rust Book][book] 的第 18 章涵盖了所有不同种类的模式及其作用。`match` 的威力来自于模式的表现力和编译器确认所有可能的情况都已处理的事实。

[book]: https://github.com/rust-lang/book/tree/master/src

可以把 `match` 表达式想象成一个硬币分类机：硬币沿着带有不同大小孔的轨道滑动，硬币通过它所遇到的第一个适合的孔。同样，值会经过 `match` 中的每个模式，当值“适合”的第一个模式匹配时，值就会掉入相关的代码块以供执行。

因为我们刚刚提到了硬币，让我们用它们作为 `match` 的例子！我们可以编写一个函数，它可以接收一个未知的美国硬币，并像计数机一样确定这是哪个硬币，并返回其以美分为单位的价值，如下所示。

```rust
enum Coin {
    Penny,
    Nickel,
    Dime,
    Quarter,
}

fn value_in_cents(coin: Coin) -> u8 {
    match coin {
        Coin::Penny => 1,
        Coin::Nickel => 5,
        Coin::Dime => 10,
        Coin::Quarter => 25,
    }
}
```

#### 一个枚举和一个以枚举的变体作为模式的 `match` 表达式

让我们仔细分析 `value_in_cents` 函数中的 `match`。首先，我们列出 `match` 关键字，后跟一个表达式，在此例中为值 `coin`。这与使用 `if` 的表达式非常相似，但有一个很大的不同：对于 `if`，表达式需要返回一个布尔值，但在这里，它可以是任何类型。在此示例中，`coin` 的类型是我们在第 1 行定义的 `Coin` 枚举。

接下来是 `match` 分支。一个分支有两个部分：模式和一些代码。这里的第一个分支有一个模式，即值 `Coin::Penny`，然后是 `=>` 运算符，将模式和要运行的代码分开。在这种情况下，代码就是值 `1`。每个分支用逗号与下一个分支分隔。

当 `match` 表达式执行时，它按照顺序将结果值与每个分支的模式进行比较。如果一个模式与值匹配，则执行与该模式相关的代码。如果该模式不匹配值，则执行继续到下一个分支，与硬币分类机十分相似。我们可以根据需要添加任意多个分支：在上面的代码片段中，我们的 `match` 有四个分支。

与每个分支相关的代码是一个表达式，而匹配分支中表达式的结果值是整个 `match` 表达式返回的值。

如果 `match` 分支的代码较短，通常不会使用大括号，就像上面的代码片段中每个分支只返回一个值。如果您想在分支中运行多行代码，可以使用大括号。例如，以下代码每次用 `Coin::Penny` 调用方法时，都会打印“Lucky penny!”，但仍会返回块的最后一个值 `1`：

```rust
fn value_in_cents(coin: Coin) -> u8 {
    match coin {
        Coin::Penny => {
            println!("Lucky penny!");
            1
        }
        Coin::Nickel => 5,
        Coin::Dime => 10,
        Coin::Quarter => 25,
    }
}
```
