### 使用元组进行重构

下面的代码片段展示了我们的程序使用元组的另一个版本。

<span class="filename">文件名：src/main.rs</span>

```rust
fn main() {
    let rect1 = (30, 50);

    println!(
        "矩形的面积是 {} 平方像素。",
        area(rect1)
    );
}

fn area(dimensions: (u32, u32)) -> u32 {
    dimensions.0 * dimensions.1
}
```

#### 用元组指定矩形的宽度和高度

从某种意义上说，这个程序更好。元组让我们添加了一些结构，现在我们只需传递一个参数。但从另一个角度看，这个版本不够清晰：元组元素没有名称，所以我们的计算变得更加令人困惑，因为我们不得不索引到元组的各部分。

对于计算面积来说，宽度和高度的顺序问题不大，但如果我们想在屏幕上绘制矩形，那就很重要了！我们必须记住 `width` 是元组的索引 `0`，而 `height` 是元组的索引 `1`。如果其他人编写这段代码，他们也得弄清楚并牢记这一点。由于我们没有在代码中传达数据的意义，很容易忘记或混淆这些值从而引发错误。
