### 使用无命名字段的元组结构体创建不同类型

你也可以定义类似于元组的结构体，称为*元组结构体*。元组结构体的结构体名称提供了额外的意义，但其字段没有关联的名称；相反，它们只有字段的类型。当你想给整个元组命名并让这个元组成为与其他元组不同的类型，而像常规结构体那样命名每个字段会显得冗长或重复时，元组结构体是很有用的。

要定义一个元组结构体，从`struct`关键字开始，紧随其后的是结构体名称和元组中的类型。例如，下面是两个名为`Color`和`Point`的元组结构体的定义和使用：

```rust
    struct Color(i32, i32, i32);
    struct Point(i32, i32, i32);

    let black = Color(0, 0, 0);
    let origin = Point(0, 0, 0);
```

注意，`black`和`origin`值是不同的类型，因为它们是不同元组结构体的实例。即使结构体内的字段具有相同的类型，你定义的每个结构体都是其自己的类型。例如，接受类型为`Color`的参数的函数不能将`Point`作为参数传递，尽管这两个类型都是由三个`i32`值组成的。除此之外，元组结构体实例的行为类似于元组：你可以将它们解构为各个部分，可以使用`.`后跟索引来访问单个值，等等。

### 无任何字段的类单元结构体

你也可以定义没有任何字段的结构体！这些结构体称为*类单元结构体*，因为它们的行为类似于`()`，即单元类型。在某些情况下，如果你需要对某个类型实现一个特性而又不想在类型中存储任何数据，类单元结构体可能会很有用。我们将在[后面](course://Generic+Types,+Traits,+and+Lifetime/Traits/Traits)讨论特性。
