### 使用泛型代码的性能

您可能想知道在使用泛型类型参数时是否会有运行时成本。好消息是，Rust 实现泛型的方式使得使用泛型类型的代码并不会比使用具体类型的代码运行得更慢。

Rust 通过在编译时对使用泛型的代码执行单态化来实现这一点。*单态化*是通过在编译时填入使用的具体类型，将泛型代码转换为特定代码的过程。

在此过程中，编译器会执行与我们在本节第三个代码片段中创建泛型函数时相反的步骤：编译器会查看调用泛型代码的所有位置，并为调用泛型代码的具体类型生成代码。

让我们通过一个使用标准库 `Option<T>` 枚举的示例来看看这是如何工作的：

```rust
let integer = Some(5);
let float = Some(5.0);
```

当 Rust 编译这段代码时，它进行了单态化。在此过程中，编译器读取了在 `Option<T>` 实例中使用的值，并识别出两种 `Option<T>`：一种是 `i32`，另一种是 `f64`。因此，它将 `Option<T>` 的泛型定义扩展为 `Option_i32` 和 `Option_f64`，从而以具体的定义替换了泛型定义。

单态化后的代码如下所示。泛型 `Option<T>` 被编译器创建的具体定义所替代：

```rust
enum Option_i32 {
    Some(i32),
    None,
}

enum Option_f64 {
    Some(f64),
    None,
}

fn main() {
    let integer = Option_i32::Some(5);
    let float = Option_f64::Some(5.0);
}
```

由于 Rust 将泛型代码编译为在每个实例中指定类型的代码，因此我们在使用泛型时无需承担运行时成本。当代码运行时，它的性能如同我们手动复制每个定义一样。单态化过程使得 Rust 的泛型在运行时极为高效。
