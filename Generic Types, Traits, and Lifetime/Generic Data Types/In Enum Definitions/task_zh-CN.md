### 在枚举定义中

就像我们对待结构体那样，我们可以定义枚举来在其变体中包含泛型数据类型。让我们再看一下标准库提供的`Option<T>`枚举，我们在“枚举”一章中使用过它：

```rust
enum Option<T> {
    Some(T),
    None,
}
```

现在这个定义应该对你更有意义了。如你所见，`Option<T>`是一个关于类型`T`的泛型枚举，具有两个变体：`Some`，它包含一个类型为`T`的值，以及不包含任何值的`None`变体。通过使用`Option<T>`枚举，我们可以表达拥有可选值的抽象概念，并且由于`Option<T>`是泛型的，我们可以使用此抽象概念，无论可选值的类型是什么。

枚举也可以使用多个泛型类型。在“可恢复与不可恢复错误”一章中我们使用的`Result`枚举的定义就是一个例子：

```rust
enum Result<T, E> {
    Ok(T),
    Err(E),
}
```

`Result`枚举在两个类型`T`和`E`上是泛型的，具有两个变体：`Ok`，它包含一个类型为`T`的值，以及`Err`，它包含一个类型为`E`的值。这个定义使得使用`Result`枚举方便无比，特别是在我们有可能成功（返回某种类型`T`的值）或失败（返回某种类型`E`的错误）的操作时。实际上，我们在“打开一个文件”代码片段中使用了这一点（“错误处理”中“使用Result的可恢复错误”部分），其中当文件成功打开时，`T`被填充为`std::fs::File`类型，而在文件打开出错时，`E`被填充为`std::io::Error`类型。

当你在代码中发现多个结构体或枚举定义，它们仅在其包含值的类型上有所不同时，你可以通过使用泛型类型来避免重复。
