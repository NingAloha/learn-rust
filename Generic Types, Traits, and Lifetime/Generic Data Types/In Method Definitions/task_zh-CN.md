### 方法定义中

我们可以在结构体和枚举上实现方法（正如我们在“结构体”一章中所做的）并在其定义中使用泛型类型。下面的代码片段展示了我们在上面定义的 `Point<T>` 结构体，其中实现了一个名为 `x` 的方法。

```rust
struct Point<T> {
    x: T,
    y: T,
}

impl<T> Point<T> {
    fn x(&self) -> &T {
        &self.x
    }
}

fn main() {
    let p = Point { x: 5, y: 10 };

    println!("p.x = {}", p.x());
}
```

#### 在 `Point<T>` 结构体上实现一个名为 `x` 的方法，该方法将返回对类型为 `T` 的 `x` 字段的引用。

这里，我们在 `Point<T>` 上定义了一个名为 `x` 的方法，该方法返回对 `x` 字段中数据的引用。

注意，我们必须在 `impl` 后面声明 `T`，以便我们能够在类型 `Point<T>` 上实现方法。通过在 `impl` 后声明 `T` 作为一个泛型类型，Rust 可以识别出 `Point` 中尖括号里的类型是一个泛型类型而不是具体类型。

例如，我们可以只在 `Point<f32>` 实例上实现方法，而不是在任何泛型类型的 `Point<T>` 实例上实现。下面我们使用具体类型 `f32`，意味着在 `impl` 后不需要声明任何类型。

```rust
impl Point<f32> {
    fn distance_from_origin(&self) -> f32 {
        (self.x.powi(2) + self.y.powi(2)).sqrt()
    }
}
```

#### 一个 `impl` 块仅适用于泛型类型参数 `T` 的特定具体类型的结构体。

这段代码表示类型 `Point<f32>` 将拥有一个名为 `distance_from_origin` 的方法，而其他 `Point<T>` 的实例如果 `T` 不是 `f32` 类型则不会定义此方法。该方法计算我们的点到坐标 (0.0, 0.0) 的距离，并使用仅适用于浮点类型的数学运算。
