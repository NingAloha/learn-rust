### 定义特征

一个类型的行为由我们可以在该类型上调用的方法组成。如果我们可以在所有这些类型上调用相同的方法，则不同的类型共享相同的行为。特征定义是一种将方法签名组合在一起，以定义实现某些目的所需的一组行为的方法。

例如，假设我们有多个结构体，它们保存着不同种类和数量的文本：`NewsArticle` 结构体保存着在特定地点发布的新闻故事，而 `Tweet` 则最多可以容纳280个字符，并附带说明它是新推文、转推还是对另一条推文的回复的元数据。

我们想要制作一个媒体汇聚库，该库可以展示可能存储在 `NewsArticle` 或 `Tweet` 实例中的数据摘要。要实现这一点，我们需要每种类型的摘要，并且需要通过调用实例上的 `summarize` 方法来请求该摘要。下面的代码片段展示了一个 `Summary` 特征的定义，它表达了这种行为。

```rust,noplayground
pub trait Summary {
    fn summarize(&self) -> String;
}
```

#### 由 `summarize` 方法提供行为的 `Summary` 特征

在这里，我们使用 `trait` 关键字然后是特征的名称来声明一个特征，在这个例子中是 `Summary`。在大括号内，我们声明描述实现此特征的类型行为的方法签名，在这个例子中是 `fn summarize(&self) -> String`。

在方法签名之后，我们使用分号，而不是在大括号内提供实现。每个实现此特征的类型都必须为方法的主体提供自己的自定义行为。编译器将强制任何具有 `Summary` 特征的类型都要用这个签名定义 `summarize` 方法。

一个特征可以在其主体中包含多个方法：方法签名每行列出一个，每行以分号结尾。
