### 借用检查器

Rust编译器有一个*借用检查器*，它通过比较作用域来判断所有借用是否有效。下面的代码清单显示了与前一个相同的代码，但添加了变量生命周期的注释。

```rust,ignore,does_not_compile
{
    let r;                // ---------+-- 'a
                          //          |
    {                     //          |
        let x = 5;        // -+-- 'b  |
        r = &x;           //  |       |
    }                     // -+       |
                          //          |
    println!("r: {}", r); //          |
}                         // ---------+
```

#### `r` 和 `x` 的生命周期注解，分别命名为 `'a` 和 `'b`

在这里，我们将 `r` 的生命周期标注为 `'a`，`x` 的生命周期标注为 `'b`。如您所见，内部 `'b` 块远小于外部 `'a` 生命周期块。在编译时，Rust比较两个生命周期的大小，并发现 `r` 的生命周期为 `'a`，但它引用的内存生命周期为 `'b`。由于 `'b` 比 `'a` 短：引用的对象没有活得跟引用一样长，该程序被拒绝编译。

下面的代码清单修复了代码，这样就没有悬垂引用，并且可以无错误地编译。

```rust
    {
        let x = 5;            // ----------+-- 'b
                              //           |
        let r = &x;           // --+-- 'a  |
                              //   |       |
        println!("r: {}", r); //   |       |
                              // --+       |
    }                         // ----------+
```

#### 一个有效的引用，因为数据的生命周期比引用更长

在这里，`x` 的生命周期为 `'b`，在这种情况下比 `'a` 大。这意味着 `r` 可以引用 `x`，因为Rust知道在 `x` 有效时，`r` 中的引用始终是有效的。

现在您知道了引用的生命周期在哪里以及Rust如何分析生命周期以确保引用始终有效，让我们在函数的上下文中探索参数和返回值的通用生命周期。
