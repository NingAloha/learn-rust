### 生命周期标注语法

生命周期标注不会改变任何引用的生存时间。正如函数可以接受任意类型当签名指定了一个泛型类型参数时，通过指定一个泛型生命周期参数，函数也可以接受具有任意生命周期的引用。生命周期标注描述了多个引用之间生命周期的关系，而不影响生命周期本身。

生命周期标注的语法稍微有些特殊：生命周期参数的名称必须以撇号（`'`）开头，通常为全小写且非常简短，就像泛型类型一样。大多数人使用名称`'a`。我们将生命周期参数标注放在引用的`&`之后，用空格将标注与引用的类型分开。

以下是一些示例：一个没有生命周期参数的`i32`引用，一个拥有名为`'a`的生命周期参数的`i32`引用，以及一个也具有生命周期`'a`的`i32`的可变引用。

```rust,ignore
&i32        // 一个引用
&'a i32     // 一个具有显式生命周期的引用
&'a mut i32 // 一个具有显式生命周期的可变引用
```

单一的生命周期标注本身意义不大，因为标注的目的是告诉Rust关于多个引用的泛型生命周期参数之间的相互关系。比如，假设我们有一个函数，参数`first`是一个带有生命周期`'a`的`i32`引用。该函数还有另一个名为`second`的参数，另一个带有生命周期`'a`的`i32`引用。生命周期标注表明引用`first`和`second`都必须至少与那个泛型生命周期一样长。
