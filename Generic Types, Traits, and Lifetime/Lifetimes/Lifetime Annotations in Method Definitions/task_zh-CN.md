### 方法定义中的生命周期注解

当我们在带生命周期的结构体上实现方法时，我们使用与泛型类型参数相同的语法，如章节“泛型数据类型”中所示的“使用与结构体定义中不同泛型类型的方法”中的示例所示。我们声明和使用生命周期参数的位置取决于它们是否与结构体字段或方法参数和返回值相关。

结构体字段的生命周期名称始终需要在 `impl` 关键字之后声明，然后在结构体名称之后使用，因为这些生命周期是结构体类型的一部分。

在 `impl` 块中的方法签名里，引用可能与结构体字段中的引用的生命周期相关联，也可能是独立的。此外，生命周期省略规则通常使得在方法签名中不需要生命周期注解。让我们看几个使用之前在本节中定义的名为 `ImportantExcerpt` 的结构体的例子。

首先，我们将使用一个名为 `level` 的方法，其唯一的参数是对 `self` 的引用，返回值为 `i32`，它不是对任何东西的引用：

```rust
impl<'a> ImportantExcerpt<'a> {
    fn level(&self) -> i32 {
        3
    }
}
```

在 `impl` 之后的生命周期参数声明及其在类型名称之后的使用是必要的，但由于第一个省略规则的缘故，我们不需要注解对 `self` 的引用的生命周期。

这里有一个应用第三个生命周期省略规则的例子：

```rust
impl<'a> ImportantExcerpt<'a> {
    fn announce_and_return_part(&self, announcement: &str) -> &str {
        println!("Attention please: {}", announcement);
        self.part
    }
}
```

有两个输入生命周期，所以 Rust 应用第一个生命周期省略规则，并为 `&self` 和 `announcement` 赋予它们各自的生命周期。然后，由于参数之一是 `&self`，返回类型获得了 `&self` 的生命周期，所有生命周期都已被考虑在内。
