### 消耗迭代器的方法

`Iterator` 特性在标准库中提供了许多默认实现的方法；您可以通过查阅 `Iterator` 特性的标准库 API 文档来了解这些方法。这些方法中有一些在其定义中调用了 `next` 方法，因此在实现 `Iterator` 特性时需要实现 `next` 方法。

调用 `next` 的方法被称为_消耗适配器_，因为调用它们会用尽迭代器。一个例子是 `sum` 方法，它获取迭代器的所有权并通过反复调用 `next` 迭代项，因此消耗了迭代器。在迭代过程中，它将每一项加到累计总和中，并在迭代完成时返回总和。下面的代码片段包含了一个测试，展示了 `sum` 方法的使用：

```rust
    #[test]
    fn iterator_sum() {
        let v1 = vec![1, 2, 3];

        let v1_iter = v1.iter();

        let total: i32 = v1_iter.sum();

        assert_eq!(total, 6);
    }
```

##### 调用 sum 方法来获取迭代器中所有项的总和

在调用 `sum` 之后，我们不能再使用 `v1_iter`，因为 `sum` 获取了我们在其上调用的迭代器的所有权。
