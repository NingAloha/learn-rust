## 用迭代器处理一系列项目

迭代器模式允许您依次对一系列项目执行某些任务。迭代器负责执行遍历每个项目的逻辑，并确定序列何时结束。当您使用迭代器时，您无需重新实现该逻辑。

在 Rust 中，迭代器是_惰性_的，意味着在调用消耗迭代器以使用其方法之前，它们没有效果。例如，下面代码片段中的代码通过调用在 `Vec<T>` 上定义的 `iter` 方法来创建一个对向量 `v1` 项目的迭代器。这段代码本身没有做任何有用的事情。

```rust
    let v1 = vec![1, 2, 3];

    let v1_iter = v1.iter();
```

##### 创建一个迭代器

一旦我们创建了一个迭代器，我们可以以多种方式使用它。在“常用编程概念/如果”中，我们使用迭代器与 `for` 循环一起执行某些代码在每个项目上，尽管我们直到现在才略过 `iter` 的调用到底做了什么。

下一个代码片段中的示例将创建迭代器与在 `for` 循环中使用迭代器分开。迭代器存储在 `v1_iter` 变量中，并且此时没有发生遍历。当调用 `for` 循环使用 `v1_iter` 中的迭代器时，迭代器中的每个元素在循环的一次迭代中使用，打印出每个值。

```rust
    let v1 = vec![1, 2, 3];

    let v1_iter = v1.iter();

    for val in v1_iter {
        println!("Got: {}", val);
    }
```

##### 在 for 循环中使用迭代器

在没有标准库提供迭代器的语言中，您可能会通过从索引 0 开始一个变量，使用该变量索引到向量中以获取值，并在循环中递增变量值，直到达到向量中项目的总数来编写相同的功能。
