### 创建一个通道

首先，在下面的示例中，我们将创建一个通道，但不对其进行任何操作。请注意，这段代码还不能编译，因为 Rust 无法确定我们想通过通道发送的值的类型。

```rust
    use std::sync::mpsc;

    fn main() {
        let (tx, rx) = mpsc::channel();
    }
```

##### 创建通道并将两部分指定给 tx 和 rx

我们使用 `mpsc::channel` 函数创建一个新的通道；`mpsc` 代表_多生产者，单消费者_。简单来说，Rust 标准库实现通道的方式意味着一个通道可以有多个_发送_端来生成值，但只有一个_接收_端来消费这些值。可以想象成多个小溪流入一条大河中：任何一条溪流里发送的东西最终都会到达大河中。我们现在从单生产者开始，但在让这个例子正常工作后，我们会添加多个生产者。

`mpsc::channel` 函数返回一个元组，其第一个元素是发送端，而第二个元素是接收端。在许多领域中，`tx` 和 `rx` 分别传统上用作_发送器_和_接收器_的缩写，因此我们将变量命名为这样的方式以指示每一端。我们使用一个模式在 `let` 语句中解构元组；我们将在第 18 章讨论 `let` 语句中的模式和解构的使用。以这种方式使用 `let` 语句是提取 `mpsc::channel` 返回的元组中各个部分的一种便捷方法。
