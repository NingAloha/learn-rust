## 使用 `assert!` 进行练习

测试对于确保代码按预期工作非常重要。

这个测试存在问题 —— 使测试能够编译！使测试通过！使测试失败！

<div class="hint">
  你甚至不需要编写任何代码来进行测试——你可以只测试一些值并运行，即便在现实生活中你不会那样做。
  <code>assert!</code> 是一个需要参数的宏。
  根据参数的值，<code>assert!</code> 将不执行任何操作（在这种情况下，测试通过）或者 <code>assert!</code> 将会触发异常（在这种情况下，测试失败）。
  因此，尝试给 <code>assert!</code> 不同的值，并查看哪些能编译，哪些能通过，哪些会失败。
</div>
