### 使用嵌套路径清理大型use列表

如果我们使用同一个crate或模块中定义的多个项，把每一项列出在单独的一行可能会占用文件中很多垂直空间。例如，这两条`use`语句把`std`中的项引入到作用域中：

```rust
    use std::cmp::Ordering;
    use std::io;
    // ---snip---
```

相反，我们可以使用嵌套路径在一行中引入相同的项。我们通过指定路径的公共部分，后跟两个冒号，以及用大括号括起来的不同路径部分的列表，如下所示：

```rust
    use std::{cmp::Ordering, io};
    // ---snip---
```

##### 指定嵌套路径以将具有相同前缀的多个项引入作用域

在较大的程序中，通过使用嵌套路径从同一crate或模块导入多项项可以显著减少需要的单独`use`语句的数量！

我们可以在路径中的任何级别使用嵌套路径，这在合并两个共享子路径的`use`语句时非常有用。例如，下面的代码片段显示了两个`use`语句：一个将`std::io`引入作用域，另一个将`std::io::Write`引入作用域。

```rust
    use std::io;
    use std::io::Write;
```

##### 两个use语句，其中一个是另一个的子路径

这两个路径的公共部分是`std::io`，这就是完整的第一个路径。要将这两个路径合并为一个`use`语句，我们可以在嵌套路径中使用`self`，如下例所示。

```rust
    use std::io::{self, Write};
```

##### 将路径合并为一个use语句

这一行将`std::io`和`std::io::Write`引入作用域。
