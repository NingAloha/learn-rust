## 函数体包含语句和表达式

函数体由一系列语句组成，可能以一个表达式结束。到目前为止，我们只介绍了不带结束表达式的函数，但您已经看到语句的一部分是一个表达式。因为 Rust 是一种基于表达式的语言，这一点理解起来非常重要。其他语言没有这种区别，所以让我们来看看什么是语句和表达式，以及它们的不同之处如何影响函数体。

我们实际上已经使用了语句和表达式。_语句_ 是执行某些操作且不返回值的指令。_表达式_ 计算并得出一个结果值。我们来看一些例子。

使用 `let` 关键字创建一个变量并赋值是一个语句。在下面的代码中，`let y = 6;` 是一个语句。

```rust
fn main() {
    let y = 6;
}
```
##### 包含一个语句的主函数声明示例

函数定义也是语句；整个前面的例子本身就是一个语句。

语句不返回值。因此，您不能将 `let` 语句赋给另一个变量，正如以下代码尝试的那样；您会得到一个错误：

```rust
fn main() {
    let x = (let y = 6);
}
```

当您运行这个程序时，您会得到如下错误：

```text
$ cargo run
   Compiling functions v0.1.0 (file:///projects/functions)
error: expected expression, found statement (`let`)
 --> src/main.rs:2:14
  |
2 |     let x = (let y = 6);
  |              ^^^
  |
  = note: variable declaration using `let` is a statement
```

`let y = 6` 语句不返回值，因此没有任何可供 `x` 绑定的内容。这与其他语言（如 C 和 Ruby）中的情况不同，在那些语言中赋值会返回赋值的值。在那些语言中，您可以写 `x = y = 6`，并让 `x` 和 `y` 都有值 `6`；在 Rust 中不是这样。

表达式会计算并形成您在 Rust 中编写的大部分代码。考虑一个简单的数学操作，比如 `5 + 6`，它是一个计算出 `11` 的表达式。表达式可以成为语句的一部分：在示例 3-1 中，语句 `let y = 6;` 中的 `6` 是一个计算出值 `6` 的表达式。调用函数是一个表达式。调用宏是一个表达式。用于创建新作用域的块 `{}` 是一个表达式，例如：

```rust
fn main() {
    let x = 5;

    let y = {
        let x = 3;
        x + 1
    };

    println!("The value of y is: {}", y);
}
```

这个表达式：

```rust
{
    let x = 3;
    x + 1
}
```

是一个块，在这种情况下，它计算出 `4`。该值作为 `let` 语句的一部分绑定到 `y`。注意 `x + 1` 行末尾没有分号，这与您之前看到的大多数行不同。表达式不包括结尾分号。如果您在表达式末尾添加分号，它将变成一个语句，然后不会返回值。在您接下来探索函数返回值和表达式时，请记住这一点。
