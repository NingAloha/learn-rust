## 整型

_整型_ 是没有小数部分的数字。在第2课中，我们使用了一种整型，即 `u32` 类型。这个类型声明表示它关联的值应该是一个无符号整数（有符号整数类型以 `i` 开头，而不是 `u`），它占用32位空间。下表展示了Rust中内置的整型。签名和无签名列中的每个变体（例如，i16）都可以用于声明整型值的类型。

| 长度    | 有符号 | 无符号  |
|---------|--------|---------|
| 8位     | i8     | u8      |
| 16位    | i16    | u16     |
| 32位    | i32    | u32     |
| 64位    | i64    | u64     |
| 128位   | i128   | u128    |
| 架构    | isize  | usize   |

##### 表格：Rust中的整型

每个变体可以是有符号或无符号的，并且有明确的大小。有符号_和_无符号_指的是数字是否可能为负或正——换句话说，就是数字是否需要有符号（有符号）或只会始终为正，因此可以表示为没有符号（无符号）。这就像在纸上写数字：当符号重要时，数字用加号或减号表示；然而，当可以安全地假设数字为正时，它就显示为无符号。有符号数字使用[二进制补码](https://en.wikipedia.org/wiki/Two%27s_complement)表示法存储。

每个有符号变体可以存储从 -($2^{n-1}$) 到 $2^{n - 1}$-1 （包括两端）的数字，其中 _n_ 是该变体使用的位数。因此，`i8` 可以存储从 -($2^7$) 到 $2^7$-1 的数字，即 -128 到 127。无符号变体可以存储从 0 到 $2^n$-1 的数字，所以 `u8` 可以存储从 0 到 $2^8$-1 的数字，即 0 到 255。

此外，`isize` 和 `usize` 类型取决于您的程序运行的计算机类型：如果是64位架构则为64位，如果是32位架构则为32位。

您可以将整数字面量以下表显示的任何形式书写。需要注意的是，除了字节字面量之外，所有数字字面量都可以带有类型后缀，例如 `57u8`，以及作为视觉分隔符的下划线，例如 `1_000`。

| 数字字面量  | 示例         |
|-------------|--------------|
| 十进制      | 98_222       |
| 十六进制    | 0xff         |
| 八进制      | 0o77         |
| 二进制      | 0b1111_0000  |
| 字节 (仅限u8) | b'A'        |

##### 表格：Rust中的整数字面量

那么，您该如何选择使用哪种类型的整数呢？如果不确定，Rust的默认值通常是好的选择，整数类型默认为 `i32`：此类型通常是最快的，即使在64位系统上也是如此。您主要在某种集合进行索引时会使用 `isize` 或 `usize`。
