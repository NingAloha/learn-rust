## 数据类型

在 Rust 中，每个值都属于某种 _数据类型_，这会告诉 Rust 使用了哪种数据，以便它知道如何处理这些数据。在本节课中，我们将研究标量类型，这类类型代表单一的值。

请记住，Rust 是一种 _静态类型语言_，这意味着它必须在编译时知道所有变量的类型。编译器通常可以根据值和我们如何使用它来推断我们想使用的类型。在可能存在多种类型的情况下，比如当我们使用 `parse` 将 `String` 转换为数值类型时，我们必须添加类型注释，如下所示：

```rust
let guess: u32 = "42".parse().expect("不是一个数字！");
```

如果我们在此处不添加类型注释，Rust 将显示以下错误，这意味着编译器需要我们提供更多信息来确定我们想使用的类型：

```text
error[E0282]: 需要类型注释
 --> src/main.rs:2:9
  |
2 |     let guess = "42".parse().expect("不是一个数字！");
  |         ^^^^^
  |         |
  |         无法推断 `_` 的类型
  |         考虑为 `guess` 指定一个类型
```

你会看到其他数据类型的不同类型注释。
