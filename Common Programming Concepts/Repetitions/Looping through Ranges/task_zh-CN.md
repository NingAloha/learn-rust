## 使用for循环遍历范围

`for`循环的安全性和简洁性使其成为Rust中最常用的循环结构。即使在你想要运行某段代码一定次数的情况下，比如在"使用while循环在条件为真时运行代码的例子"中使用`while`循环的倒计时例子，大多数Rustacean会使用`for`循环。这样做的方法是使用`Range`，它是一个由标准库提供的类型，可以生成从一个数字开始到另一个数字之前的所有数字的序列。

下面是使用`for`循环和我们尚未讨论过的另一种方法，`rev`，来反转范围的倒计时示例：

```rust
fn main() {
    for number in (1..4).rev() {
        println!("{}!", number);
    }
    println!("LIFTOFF!!!");
}
```
