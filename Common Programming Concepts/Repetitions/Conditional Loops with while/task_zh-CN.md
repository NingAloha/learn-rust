### 条件循环使用 while

在循环中评估条件对程序经常很有用。当条件为真时，循环运行。当条件不再为真时，程序调用 `break`，停止循环。可以使用 `loop`、`if`、`else` 和 `break` 的组合来实现这种循环类型；如果您愿意，可以在程序中尝试一下。

然而，这种模式非常常见，以至于 Rust 为其提供了内置语言结构，称为 `while` 循环。下面的列表中使用了 while：程序循环三次，每次递减计数，然后循环结束后，再打印一条消息并退出。

```rust
fn main() {
    let mut number = 3;

    while number != 0 {
        println!("{}!", number);

        number -= 1;
    }

    println!("LIFTOFF!!!");
}
```
##### 使用 while 循环在条件为真时运行代码的示例

这个结构消除了如果使用 `loop`、`if`、`else` 和 `break` 则必要的许多嵌套，使代码更清晰。当条件为真时，代码运行；否则，退出循环。
