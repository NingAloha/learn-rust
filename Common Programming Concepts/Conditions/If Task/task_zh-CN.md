## 返回较大的数字

完成这个函数以返回较大的数字！

不要使用：

* `return`
* 另一个函数调用
* 附加变量

<div class="hint">
  如果你愿意，这可以在一行中完成！

  一些来自其他语言的类似例子：
  - 在 C(++) 中这样写：`a > b ? a : b`
  - 在 Python 中这样写：`a if a > b else b`
</div>
<div class="hint">
  记住在 Rust 中：

  * <code>if</code> 条件不需要用括号括起来
  * <code>if</code> / <code>else</code> 条件是表达式
  * 每个条件后面跟着一个 <code>{}</code> 块。
</div>
