### 常量

像不可变变量一样，_常量_ 是绑定到一个名称且不允许更改的值，但在常量和变量之间有一些区别。

首先，你不能对常量使用 `mut`。常量不仅默认不可变——它们始终不可变。你使用 `const` 关键字声明常量，而不是 `let` 关键字，并且值的类型 _必须_ 注解。我们将在下一节课中讲述类型和类型注解，[基本数据类型](course://Common Programming Concepts/Basic Data Types)，所以现在不用担心细节。只需知道你必须始终注解类型。

常量可以在任何作用域中声明，包括全局作用域，这使得常量对于代码多个部分需要知道的值非常有用。

最后一个区别是常量只能设置为常量表达式，而不是可以仅在运行时计算的值的结果。

以下是一个常量声明的示例：

```rust

const THREE_HOURS_IN_SECONDS: u32 = 60 * 60 * 3;
```

常量的名称是 `THREE_HOURS_IN_SECONDS`，其值设置为将 60（每分钟的秒数）乘以 60（每小时的分钟数）再乘以 3（我们在此程序中想要计数的小时数）的结果。Rust 对常量的命名惯例是在单词之间使用下划线，并且全部大写。编译器能够在编译时评估一组有限的操作，这使我们可以选择以一种更容易理解和验证的方式写出这个值，而不是设置此常量为值 10,800。有关声明常量时可以使用的操作的更多信息，请参阅 [Rust 参考的常量求值] (https://doc.rust-lang.org/stable/reference/const_eval.html) 小节。

常量在程序运行的整个时间内在它们被声明的作用域内有效。这个特性使常量对于程序中多个部分可能需要知道的应用领域的值非常有用，比如游戏中任何一个玩家可以获得的最大积分数或光速。

将整个程序中使用的硬编码值命名为常量对于向未来的代码维护者传达该值的意义是有用的。如果以后需要更新硬编码值，这样也有助于使你只需要更改代码中的一个地方。
