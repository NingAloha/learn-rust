## 更改类型

让我编译！

<div class="hint">
在“可变变量绑定”中，我们已经学习了如何使用一个特殊的关键字将不可变变量变为可变。不幸的是，这对我们在本练习中帮助不大，因为我们想要给现有变量分配一个不同类型的值。有时你可能还想重用现有的变量名，因为你只是在将值转换为不同的类型，就像在本练习中一样。

幸运的是，Rust 对这个问题有一个强大的解决方案：“遮蔽”！你可以在[相应的任务](course://Common Programming Concepts/Variables/Shadowing)中阅读更多关于“遮蔽”的信息。尝试使用这种技术来解决这个练习。
</div>
