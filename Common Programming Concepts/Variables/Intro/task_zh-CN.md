## 常见的编程概念

在本节中，我们将讨论常见的编程概念，例如：

* 变量与可变性
* 数据类型
* 函数
* 控制流

本节介绍了几乎每种编程语言中都会出现的概念及其在 Rust 中的工作方式。许多编程语言在核心方面有许多共同之处。本章介绍的概念没有一个是 Rust 独有的，但我们将在 Rust 的背景下讨论它们，并解释使用这些概念的惯例。

具体来说，您将学习变量、基本类型、函数、注释和控制流。这些基础将在每个 Rust 程序中出现，尽早学习它们将为您提供一个强大的起点。

### 关键字

Rust 语言有一组保留给语言使用的关键字，就像其他语言一样。请记住，您不能将这些词用作变量或函数的名称。大多数关键字有特殊的意义，您将在 Rust 程序中使用它们来完成各种任务；有些关键字目前没有关联的功能，但已被保留用于将来可能添加到 Rust 的功能。您可以在[附录 A](https://doc.rust-lang.org/stable/book/appendix-01-keywords.html)中找到关键字列表。
