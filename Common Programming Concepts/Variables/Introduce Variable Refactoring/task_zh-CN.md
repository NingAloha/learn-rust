## 掌握IDE：引入变量重构

在1993年，一位开发者编写了一段代码，用于计算十年、五年和一年前的年份。

到了2021年，另一位开发者查看了这段代码，发现它不再产生正确的结果。

这位开发者决定[重构代码](https://en.wikipedia.org/wiki/Code_refactoring)，将 `1993` 提取到一个名为 `year` 的新变量中。这样，以后接触到这段代码的开发者就可以通过只更改一个地方而不是三个地方来修复它。

让我们也来重构这段代码！

%IDE_NAME% 有一个名为**“引入变量重构”**的便捷功能，允许您快速完成此操作。

选择 `1993` 的任意出现，然后按 &shortcut:IntroduceVariable; 或从右键菜单中选择 *重构 -> 引入变量...*。

*注意*：您还可以使用 &shortcut:IntroduceConstant; 或从右键菜单中选择 *重构 -> 引入常量...* 来创建常量。
