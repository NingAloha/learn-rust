## 创建一个数组

创建一个至少包含100个元素的数组。运行 main.rs 文件以查看代码输出。不要更改返回的行 — 测试会检查字符串 `"Wow, that's a big array!"`。

<div class="hint">
  这里有一种简写方法可以初始化具有一定大小的数组，这样就不需要手动输入100个项目（不过如果你愿意的话也可以这么做！）。

  例如，你可以这样做：
  ```rust
  let array = ["Are we there yet?"; 10];
  ```
</div>
