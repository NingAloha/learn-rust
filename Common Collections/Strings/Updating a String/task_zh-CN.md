### 更新字符串

`String` 可以增长其大小，并且其内容可以更改，就像 `Vec<T>` 的内容一样，如果您向其推送更多数据。此外，您可以方便地使用 `+` 运算符或 `format!` 宏来连接 `String` 值。

#### 使用 `push_str` 和 `push` 追加到字符串

我们可以使用 `push_str` 方法追加字符串切片来增长 `String`，如下代码片段所示。

```rust
    let mut s = String::from("foo");
    s.push_str("bar");
```

##### 使用 push_str 方法将字符串切片追加到字符串的示例

在这两行代码之后，`s` 将包含 `foobar`。`push_str` 方法接收一个字符串切片，因为我们不一定想取得参数的所有权。例如，下面的代码片段展示了如果在将 `s2` 的内容追加到 `s1` 后无法使用 `s2` 是多么的不尽人意。

```rust
    let mut s1 = String::from("foo");
    let s2 = "bar";
    s1.push_str(s2);
    println!("s2 is {}", s2);
```

##### 在将其内容追加到字符串后使用字符串切片

如果 `push_str` 方法取得了 `s2` 的所有权，我们将无法在最后一行打印其值。然而，此代码按我们所期望的那样工作！

`push` 方法接收一个字符作为参数，并将其添加到 `String` 中。以下代码片段展示了使用 `push` 方法将字母 _l_ 添加到 `String`。

```rust
    let mut s = String::from("lo");
    s.push('l');
```

##### 使用 push 方法将一个字符添加到字符串值

此代码的结果是，`s` 将包含 `lol`。

#### 使用 `+` 运算符或 `format!` 宏进行连接

通常，您可能希望组合两个现有的字符串。一种方法是使用 `+` 运算符，如下所示。

```rust
    let s1 = String::from("Hello, ");
    let s2 = String::from("world!");
    let s3 = s1 + &s2; // 注意 s1 已经被移动到这里，不能再被使用
```

##### 使用 + 运算符将两个字符串值组合成一个新的字符串值

此代码的结果字符串 `s3` 将包含 `Hello, world!`。在加法后 `s1` 不再有效，且我们使用了 `s2` 的引用，这与我们使用 `+` 运算符时被调用的方法签名有关。`+` 运算符使用 `add` 方法，其签名看起来如下：

```rust
    fn add(self, s: &str) -> String {
```

这不是标准库中的确切签名：在标准库中，`add` 是使用泛型定义的。这里，我们在查看用具体类型替换了泛型后的 `add` 签名，这在我们使用 `String` 值调用该方法时会发生。当我们讨论泛型时，会在“泛型类型、特征和生命周期”一章中详细解释这个签名，它为我们理解 `+` 运算符的微妙之处提供了线索。

首先，`s2` 具有 `&`，意味着我们是在将第二个字符串的_引用_添加到第一个字符串，因为 `add` 函数的 `s` 参数：我们只能将一个 `&str` 添加到一个 `String`；我们不能将两个 `String` 值相加。但等等——`&s2` 的类型是 `&String`，而不是如 `add` 的第二个参数中所指定的 `&str`。那么为什么“使用 + 运算符将两个字符串值组合成一个新的字符串值”的示例能够编译？

我们能够在对 `add` 的调用中使用 `&s2` 的原因是编译器可以_强制转换_ `&String` 参数为 `&str`。在调用 `add` 方法时，Rust 使用了_解引用强制转换_，这里将 `&s2` 变为 `&s2[..]`。在 [Rust 图书](https://doc.rust-lang.org/book/ch15-00-smart-pointers.html)第15章中我们将更深入地讨论解引用强制转换。由于 `add` 不会取得 `s` 参数的所有权，`s2` 在此操作后仍将是有效的 `String`。

其次，我们可以在签名中看到 `add` 取得 `self` 的所有权，因为 `self` 没有 `&`。这意味着在“使用 + 运算符将两个字符串值组合成一个新的字符串值”示例中，`s1` 将被移动到 `add` 调用中，并在那之后不再有效。因此，尽管 `let s3 = s1 + &s2;` 看起来会复制这两个字符串并创建一个新的字符串，但实际上这个语句取得了 `s1` 的所有权，追加了 `s2` 的内容的副本，然后返回结果的所有权。换句话说，看起来似乎是在进行大量复制，但并不是；实现比复制更高效。

如果我们需要连接多个字符串，`+` 运算符的行为将变得笨拙：

```rust
    let s1 = String::from("tic");
    let s2 = String::from("tac");
    let s3 = String::from("toe");

    let s = s1 + "-" + &s2 + "-" + &s3;
```

此时，`s` 将是 `tic-tac-toe`。由于 `+` 和 `"` 字符众多，很难看清发生了什么。对于更复杂的字符串组合，我们可以使用 `format!` 宏：

```rust
    let s1 = String::from("tic");
    let s2 = String::from("tac");
    let s3 = String::from("toe");

    let s = format!("{}-{}-{}", s1, s2, s3);
```

此代码也将 `s` 设置为 `tic-tac-toe`。`format!` 宏的工作原理和 `println!` 一样，但不是将输出打印到屏幕上，而是返回一个包含内容的 `String`。使用 `format!` 的代码版本更容易阅读，并且不接管其任何参数的所有权。
