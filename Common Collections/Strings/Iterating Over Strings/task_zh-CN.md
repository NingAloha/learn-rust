### 字符串迭代的方法

幸运的是，你可以通过其他方式访问字符串中的元素。

如果你需要针对各个 Unicode 标量值进行操作，最好的方式是使用 `chars` 方法。在字符串 “नमस्ते” 上调用 `chars`，将分离并返回六个 `char` 类型的值，你可以通过迭代结果来访问每个元素：

```rust
    for c in "नमस्ते".chars() {
        println!("{}", c);
    }
```

这段代码将打印如下内容：

```text
    न
    म
    स
    ्
    त
    े
```

`bytes` 方法返回的是每个原始字节，这可能适合你的需求：

```rust
    for b in "नमस्ते".bytes() {
        println!("{}", b);
    }
```

这段代码将打印出构成此 `String` 的18个字节：

```text
    224
    164
    // --snip--
    165
    135
```

但请记住，有效的 Unicode 标量值可能由多个字节组成。

从字符串中获取字形簇比较复杂，因此标准库不提供此功能。如果你需要这种功能，可以在 [crates.io](https://crates.io) 上找到相应的 crates。
