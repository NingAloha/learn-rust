### 读取向量中的元素

现在您已经知道如何创建、更新和销毁向量，了解如何读取其内容是一个很好的下一步。引用存储在向量中的值有两种方法。在示例中，我们为这些函数返回的值标注了类型，以提高清晰度。

下面的代码展示了访问向量中值的两种方法，可以使用索引语法或者 `get` 方法。

```rust
    let v = vec![1, 2, 3, 4, 5];

    let third: &i32 = &v[2];
    println!("第三个元素是 {}", third);

    match v.get(2) {
        Some(third) => println!("第三个元素是 {}", third),
        None => println!("没有第三个元素。"),
    }
```

#### 使用索引语法或 get 方法访问向量中的项目

在这里需要注意两个细节。首先，我们使用索引值 `2` 来获取第三个元素：向量是从零开始按数字索引的。其次，获取第三个元素的两种方法是使用 `&` 和 `[]`，这为我们提供了一个引用，或者使用 `get` 方法并传递索引作为参数，得到一个 `Option<&T>`。

Rust 提供了两种引用元素的方法，因此当您尝试使用向量中没有元素的索引值时，可以选择程序的行为。作为示例，让我们看看程序在拥有五个元素的向量时，尝试访问索引 100 的元素会发生什么，如下所示。

```rust,should_panic,panics
    let v = vec![1, 2, 3, 4, 5];

    let does_not_exist = &v[100];
    let does_not_exist = v.get(100);
```

#### 试图访问包含五个元素的向量中索引 100 的元素

当我们运行这段代码时，第一个 `[]` 方法将导致程序崩溃，因为它引用了一个不存在的元素。这种方法最好用于当您希望程序在试图访问超出向量末尾的元素时崩溃。

当 `get` 方法传递一个超出向量范围的索引时，它返回 `None` 而不会崩溃。如果在正常情况下偶尔会访问向量范围之外的元素，可以使用这种方法。您的代码将包含处理 `Some(&element)` 或 `None` 的逻辑，正如在“枚举”一章中讨论的那样。例如，索引可能是用户输入的数字。如果他们不小心输入过大的数字并且程序得到一个 `None` 值，您可以告诉用户当前向量中有多少个项目，并给他们另一次输入有效值的机会。相比因为输入错误而导致程序崩溃，这样更友好。
