### 使用枚举存储多种类型

在本章节开始时，我们提到向量只能存储相同类型的值。这可能会不方便；确实存在需要存储不同类型元素列表的用例。幸运的是，枚举的变体是在同一个枚举类型下定义的，因此当我们需要在向量中存储不同类型的元素时，我们可以定义并使用一个枚举！

例如，假设我们希望从电子表格中获取一行的值，其中这行中的某些列包含整数，一些包含浮点数，还有一些包含字符串。我们可以定义一个枚举，其变体将保存不同的值类型，然后所有的枚举变体将被视为同一类型：枚举的类型。然后我们可以创建一个保存该枚举的向量，从而最终保存不同类型。我们在下面演示了这一点。

```rust
    enum SpreadsheetCell {
        Int(i32),
        Float(f64),
        Text(String),
    }

    let row = vec![
        SpreadsheetCell::Int(3),
        SpreadsheetCell::Text(String::from("blue")),
        SpreadsheetCell::Float(10.12),
    ];
```

#### 定义一个枚举来在单个向量中存储不同类型的值

Rust需要在编译时知道向量中将有哪些类型，以便准确知道在堆上存储每个元素需要多少内存。一个次要好处是我们可以明确允许在此向量中存储哪些类型。如果Rust允许向量持有任何类型，那么某一个或多个类型可能会在对向量元素进行的操作中引起错误。使用枚举加上`match`表达式意味着Rust将在编译时确保每个可能的情况都被处理，就像在“枚举”这一章中讨论的那样。

当你在编写程序时，如果你不知道程序在运行时会获得哪些完整类型集合以存储在向量中，枚举技术将不起作用。相反，你可以使用特征对象，我们将在[Rust图书][book]的第17章中介绍。

既然我们已经讨论了一些使用向量的最常见方式，请务必查看[API文档][vec-api]以了解标准库中`Vec<T>`定义的所有许多有用方法。例如，除了`push`，还有一个`pop`方法可以移除并返回最后一个元素。
