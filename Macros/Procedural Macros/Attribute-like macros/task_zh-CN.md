### 类似属性的宏

类似属性的宏与自定义派生宏相似，但它们不是为 `derive` 属性生成代码，而是允许你创建新的属性。它们也更加灵活：`derive` 只适用于结构体和枚举，而属性还可以应用于其他项目，例如函数。以下是使用类似属性宏的一个示例：假设你有一个名为 `route` 的属性，在使用一个 Web 应用框架时用于注解函数：

```rust
    #[route(GET, "/")]
    fn index() {
```

这个 `#[route]` 属性将由框架定义为一个过程宏。宏定义函数的签名如下所示：

```rust
    #[proc_macro_attribute]
    pub fn route(attr: TokenStream, item: TokenStream) -> TokenStream {
```

在这里，我们有两个类型为 `TokenStream` 的参数。第一个参数用于属性的内容：即 `GET, "/"` 部分。第二个参数是属性附加到的项目的主体：在这个例子中，即 `fn index() {}` 以及函数体的其余部分。

除此之外，类似属性的宏与自定义派生宏的工作方式相同：你创建一个 `proc-macro` 类型的包，并实现一个生成所需代码的函数！
