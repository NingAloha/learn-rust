## 引用的作用域

注意，引用的作用域从其引入开始，一直到该引用最后一次被使用结束。例如，以下代码可以编译，因为不可变引用的最后一次使用发生在可变引用引入之前：

```rust
    let mut s = String::from("hello");

    let r1 = &s; // 没问题
    let r2 = &s; // 没问题
    println!("{} and {}", r1, r2);
    // 在这之后 r1 和 r2 不再被使用

    let r3 = &mut s; // 没问题
    println!("{}", r3);
```

不可变引用 `r1` 和 `r2` 的作用域在它们最后一次被使用的 `println!` 之后结束，而这发生在可变引用 `r3` 被创建之前。这些作用域没有重叠，因此这段代码是允许的。编译器能够在作用域结束前识别引用不再被使用的能力称为非词法生命周期（简称 NLL），你可以在[版本指南](https://doc.rust-lang.org/edition-guide/rust-2018/ownership-and-lifetimes/non-lexical-lifetimes.html)中阅读更多相关内容。

即使借用错误有时可能让人沮丧，记住这是 Rust 编译器在早期阶段指出潜在的错误（在编译时而不是运行时）并精确显示问题所在的地方。这样你就不用去追踪为什么你的数据不是你所想的那样。
