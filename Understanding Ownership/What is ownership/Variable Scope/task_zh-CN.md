### 变量作用域

在第2章中，我们已经演示了一个Rust程序的实例。现在我们已超过基本语法，因此在示例中我们将不包含所有的 `fn main() {` 代码，所以如果你跟随学习，你需要手动将下面的示例放入一个 `main` 函数中。这样一来，我们的示例将更加简洁，使我们能够专注于实际细节而不是样板代码。

作为所有权的第一个实例，我们将看看一些变量的_作用域_。作用域是程序中某个项目有效的范围。假设我们有一个变量如下所示：

```rust
let s = "hello"
```

变量 `s` 指向一个字符串字面量，其中字符串的值被硬编码进我们程序的文本中。变量从声明的那一刻起一直到当前_作用域_结束都是有效的。下面的代码段有注释标注了变量 `s` 的有效位置。

```rust
{                      // s 在这里无效，尚未被声明
let s = "hello";   // s 从这一点开始有效

// 用 s 做一些事情
}                      // 这个作用域现在结束，s 不再有效
```

##### 变量及其有效的作用域

换句话说，有两个重要的时间点：

*   当 `s` _进入作用域_ 时，它是有效的。
*   它将保持有效，直到它_离开作用域_。
