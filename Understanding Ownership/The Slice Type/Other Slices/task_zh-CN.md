## 其他切片

顾名思义，字符串切片是特定于字符串的。但是，也有一个更通用的切片类型。请考虑这个数组：

```rust
    let a = [1, 2, 3, 4, 5];
```

正如我们可能想要引用字符串的一部分，我们也可能想引用数组的一部分。我们可以这样做：

```rust
    let a = [1, 2, 3, 4, 5];

    let slice = &a[1..3];
```

这个切片的类型是 `&[i32]`。它的工作方式与字符串切片相同，通过存储对第一个元素的引用以及一个长度。您将使用这种类型的切片来处理各种其他集合。我们将在[之后](course://Common Collections/Vectors/Intro)详细讨论这些集合。
