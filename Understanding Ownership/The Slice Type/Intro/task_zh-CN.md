## 切片类型

另一种不拥有所有权的数据类型是_切片_。切片允许你引用集合中的一段连续元素，而不是整个集合。

这是一个小的编程问题：编写一个函数，接受一个字符串并返回在该字符串中找到的第一个单词。如果函数在字符串中没有找到空格，那么整个字符串必须是一个单词，因此应该返回整个字符串。

让我们思考一下这个函数的签名：

```rust
    fn first_word(s: &String) -> ?
```

这个函数`first_word`的参数是一个`&String`。我们不想要所有权，所以这样是可以的。但我们应该返回什么呢？我们实际上并没有办法讨论字符串的一_部分_。然而，我们可以返回单词结尾的索引。我们试一试，代码片段如下所示。

```rust
    fn first_word(s: &String) -> usize {
        let bytes = s.as_bytes();

        for (i, &item) in bytes.iter().enumerate() {
            if item == b' ' {
                return i;
            }
        }

        s.len()
    }
```

##### 返回字节索引值的first_word函数

因为我们需要逐个检查`String`中的元素，看其是否是空格，所以我们将使用`as_bytes`方法将`String`转换为字节数组：

```rust
    let bytes = s.as_bytes();
```

接下来，我们使用`iter`方法创建一个字节数组的迭代器：

```rust
    for (i, &item) in bytes.iter().enumerate() {
```

我们将在第13章更详细地讨论迭代器。现在，你只需知道`iter`是一个返回集合中每个元素的方法，`enumerate`将`iter`的结果包装并将每个元素作为元组的一部分返回。`enumerate`返回的元组第一个元素是索引，第二个元素是对该元素的引用。这比我们自己计算索引更加方便。

因为`enumerate`方法返回一个元组，所以我们可以使用模式来解构这个元组，就像Rust中任何其他地方一样。因此，在`for`循环中，我们指定一个包含元组索引的`i`和元组中单个字节的`&item`的模式。因为我们从`.iter().enumerate()`获得的是对元素的引用，所以我们在模式中使用`&`。

在`for`循环内，我们使用字节文字语法搜索表示空格的字节。如果找到空格，就返回该位置。否则，就使用`s.len()`返回字符串的长度：

```rust
        if item == b' ' {
            return i;
        }
    }

    s.len()
```

我们现在有了一种找到字符串中第一个单词末尾索引的方法，但存在一个问题。我们只返回了一个`usize`，在`&String`的上下文中它才有意义。换句话说，因为它是一个独立于`String`的值，所以不能保证它将来仍然有效。考虑以下程序，它使用了前面示例中的`first_word`函数。

```rust
    fn main() {
        let mut s = String::from("hello world");

        let word = first_word(&s); // word将获得值5

        s.clear(); // 这会清空字符串，使其等于""

        // word仍然保存着值5，但这里已经没有字符串可以有意义地使用值5了。word现在完全无效了！
    }
```

##### 存储调用first_word函数的结果，然后改变String的内容

这个程序可以正常编译，也可以在调用`s.clear()`后使用`word`。因为`word`与`s`的状态没有任何关联，`word`仍然包含值`5`。我们可以用变量`s`和这个值`5`来尝试提取第一个单词，但这会导致一个错误，因为自从我们将`5`保存到`word`之后，`s`的内容已经改变。

需要担心`word`中索引与`s`中的数据不同步是乏味且容易出错的！如果我们编写一个`second_word`函数来管理这些索引，就更容易出错。它的签名将如下所示：

```rust
    fn second_word(s: &String) -> (usize, usize) {
```

现在我们需要追踪开始和结束索引，并且还有更多从某个特定状态的数据中计算出的值，但与该状态没有任何联系。我们现在有三个不相关的变量在浮动，需要保持同步。

幸运的是，Rust有一个解决方案：字符串切片。
